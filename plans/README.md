# Plans

This folder holds implementation plans written before non-trivial work — the kind of plan that would otherwise only exist transiently in a planning-mode session.

## Convention

- File name: `YYYY-MM-DD-short-title.md` (e.g. `2026-07-28-adr-and-plans-setup.md`).
- Save the plan as presented/approved, not a running log — if the approach changes significantly mid-implementation, update the file rather than leaving a stale plan behind.
- Once work is complete, leave the plan in place as a record of what was intended and why; don't delete it.

See [../docs/adr/](../docs/adr/) for the *why* behind standing architecture/data-model decisions — plans capture the *what/how* for a specific piece of work.
